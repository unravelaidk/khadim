# Khadim plugin SDKs

The SDK directory contains the language-neutral v1 contract and language
adapters for building WebAssembly packages that run in Khadim's Electron host.

<!-- prettier-ignore -->
> [!NOTE]
> This is an experimental feature currently under active development.

Use the [plugin system guide](../docs/plugins.md) for package manifests,
permissions, lifecycle, and harness operations. Choose the
[Rust SDK](./rust/README.md) for a typed production path or the
[AssemblyScript SDK](./assemblyscript/README.md) when you want to stay in the
TypeScript ecosystem.
